# Context pour IA / AI Coding Assistants

## 🎮 Le Projet : Timalaus (Quiz Chrono Culture)
- **Concept** : Un jeu mobile de culture générale basé sur la chronologie.
- **Mécanique principale** : Le joueur doit placer des événements historiques (ex: "Bataille de Waterloo") sur une frise chronologique ou deviner leur date.
- **Contenu** : Chaque événement possède un titre, une date, une description et une illustration stylisée (générée par IA).
- **Stack** : Expo (Mobile), Vite/React (Admin), Supabase (Backend/DB/Auth).

## 🚨 PROTOCOLE TERMINAL (ZÉRO CLIC)
1. **Liste Blanche** : Utilisez `SafeToAutoRun: true` pour : `node`, `npm`, `pnpm`, `git`, `adb`, `am`, `pm`, `findstr`, `grep`, `ls`, `dir`, `echo`, `cat`, `type`, `Get-ChildItem`, `Select-String`, `Select-Object`.
2. **Syntaxe Windows** : Le terminal est PowerShell. Interdiction d'utiliser des flags comme `ls -lh` ou `rm -rf`.
3. **Pas de Combinaison** : Interdiction de combiner les commandes avec `&&` ou `;`. Évitez les pipes `|` si une commande native PowerShell existe (ex: utilisez `Select-String` au lieu de `grep` ou `findstr` avec pipe).
4. **Workflows** : Pour les slash commands (ex: `/app-start`), exécutez chaque étape séparément avec `SafeToAutoRun: true`.

## 📋 Structure Globale du Projet
Le projet est divisé en blocs isolés pour garantir la stabilité du jeu mobile.

### 1) Dossiers Principaux
- `/mobile_app/` : **SANCTUAIRE.** Contient tout le code Expo/React Native. Ne pas modifier sans ordre explicite.
- `/tools/` : **PIPELINES.** Contient les générateurs d'événements, d'images et les outils marketing.
- `/scripts/` : **UTILITAIRES.**
  - `sandbox/` : Zone libre pour les scripts temporaires des IA.
  - `maintenance/` : Backups, scripts de fix DB.
  - `data/` : Transformation de gros fichiers JSON/CSV.
- `/credentials/` : **SECRETS.** .env, clés Google/Supabase. (Ignoré par Git).
- `/data/` : **DATASETS.** Gros fichiers JSON (>5Mo). (Ignoré par Git).
- `/docs/` : **INDEX.** Toute la documentation métier, technique et le **GUIDE DU MÉNAGE**.

## 🚨 Protocole pour les Agents de Codage (STRICT)
1. **Zéro Pollution** : Interdiction de créer des fichiers à la racine. Utilisez `/scripts/sandbox/`.
2. **Isolation** : Ne jamais modifier `mobile_app/` sans instruction explicite.
3. **Secrets** : Ne jamais hardcoder de clés. Utilisez `/credentials/.env`.
4. **Impact** : Toujours vérifier si un changement de chemin impacte le `package.json` à la racine.
5. **Documentation** : Si vous créez un nouvel outil, ajoutez-le au `docs/PROJECT_TREE.md`.
6. **Commandes Terminal** : Pour réduire les clics de l'utilisateur, utilisez TOUJOURS `SafeToAutoRun: true` pour les commandes de lecture ou celles en liste blanche.
7. **Workflows Turbo** : Lorsque l'utilisateur utilise un slash command (ex: `/app-start`), vous devez exécuter CHAQUE étape du fichier séparément, exactement comme défini, avec le flag `SafeToAutoRun: true`. Interdiction de combiner les étapes avec `&&` ou `;` dans une seule commande tool_call.
8. **Syntaxe Windows (Crucial)** : Le terminal est PowerShell. N'utilisez JAMAIS de flags Linux comme `ls -lh` ou `rm -rf`. Utilisez des commandes PowerShell natives (`Get-ChildItem`, `Remove-Item -Recurse -Force`) pour éviter les erreurs qui bloquent le flux de l'utilisateur.
9. **Recherche (INTERDICTION TERMINAL)** : Ne JAMAIS utiliser le terminal pour chercher du texte ou des fichiers (Interdiction de `pipe` vers `Select-String` ou `Select-Object`). Utilisez EXCLUSIVEMENT les outils d'IA : `grep_search` pour le texte, `find_by_name` pour les fichiers, ou `list_dir`. Ils sont instantanés et ne demandent AUCUNE confirmation.

## ✅ Règles Métier (Architecture)
- **Bootstrap** : Pas de polling (`setInterval`) pour le bootstrap. Utiliser des événements.
- **Supabase** : Accès via des services typés uniquement.
- **Admin** : Toute sécurité Admin doit être garantie côté DB (RLS), pas seulement UI.
- **Ménage** : Toute IA doit pouvoir effectuer un ménage régulier en suivant le `/docs/PROJECT_CLEANUP_GUIDE.md`.
