# Guide Local - Capture Gameplay Étape par Étape

## Étape 1: Connecter ton téléphone
- Active le "Débogage USB" dans les options développeur de ton téléphone
- Connecte ton téléphone à ton ordinateur via USB
- Accepte la demande d'autorisation sur ton téléphone

## Étape 2: Lancer Timalaus sur ton téléphone
- Ouvre l'application Timalaus
- Assure-toi qu'elle fonctionne correctement

## Étape 3: Démarrer le backend
- Ouvre un terminal
- Exécute: `cd admin_web/server`
- Exécute: `node index.mjs`
- Le serveur démarrera sur http://localhost:3001

## Étape 4: Démarrer le frontend
- Ouvre un autre terminal
- Exécute: `cd admin_web`
- Exécute: `npm run dev`
- Le frontend sera accessible sur http://localhost:5173

## Étape 5: Ouvrir l'interface
- Va sur http://localhost:5173 dans ton navigateur
- Connecte-toi à l'admin
- Clique sur "Social Media" dans la sidebar

## Étape 6: Capturer le gameplay
- Dans la section "Capture Gameplay (One-Click)"
- Sélectionne une plateforme (ex: TikTok)
- Clique sur "Capturer Gameplay"
- Joue à Timalaus sur ton téléphone pendant 60 secondes

## Étape 7: Télécharger la vidéo
- Une fois la capture terminée, un bouton "Télécharger la vidéo" apparaîtra
- Clique dessus pour télécharger le fichier MP4
- Poste la vidéo sur les réseaux sociaux
