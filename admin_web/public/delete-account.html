Suppression de compte et de données

Application : Timalaus — Package Android : com.pierretulle.juno2

Si vous souhaitez supprimer votre compte et vos données personnelles associées à Timalaus, envoyez une demande à l'adresse email ci-dessous.

Email de contact : quandiappli@proton.me

Informations à inclure dans votre demande

  • Votre identifiant de compte (ou email utilisé dans l'application).
  • L'objet : Demande de suppression de compte Timalaus.

Délai de traitement

Les demandes sont traitées sous 30 jours maximum après vérification d'identité.

Données supprimées

  • Compte utilisateur et profil associé.
  • Données de progression et statistiques rattachées à votre compte.

Données pouvant être conservées

Certaines données non directement identifiantes (ex. journaux techniques, obligations légales, données agrégées/anonymisées) peuvent être conservées conformément à la réglementation applicable.
