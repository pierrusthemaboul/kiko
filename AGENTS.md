# Notes projet

## Mode précision

- Le mode précision n'est **plus accessible aux joueurs** (retiré de l'app, réactivation prévue bien plus tard).
- **Ne jamais appliquer de corrections au mode précision** quand l'utilisateur demande un fix : ses demandes concernent toujours le mode classique, sauf mention explicite du contraire.
- Fichiers concernés (à ne pas modifier pour les demandes de corrections) : `mobile_app/hooks/game/usePrecisionGame.ts`, `usePrecisionAds.ts`, `components/modals/Precision*.tsx`, `components/legacy_precision/`.
